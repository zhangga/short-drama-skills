# 影片视频提示词

## 目标与边界
编译已明确的分镜，不在提示词阶段悄悄重写剧情。文字分镜负责“拍什么和为什么”，本技能负责“下游如何执行”。

## 输入与输出
输入一段 clip 的分镜、角色／场景／道具卡和实际参考文件、后端能力。输出 `视频_<clip_id>.prompt.txt` 与请求说明（模型、比例、时长、参考图编号及角色映射）。

## 执行
1. 验证分镜时间和引用。列出参考文件及用途，例如图1=角色A、图2=角色B、图3=场景；供应商的 `@图片1` 等标记以当前工具帮助为准，不能把本地路径当云端可访问 URL。
2. 开头交代画风、比例、总时长、地点、出场人物及初始空间关系。参考图人物保持锁定特征，描述换装／伤势时引用对应资产版本。
3. 逐秒段写：景别／镜头运动→人物动作链→灯光→对白／音效。指定对白的说话人、语气、语言与必要音色描述；无对白时明确使用环境声。后端不支持音频时分离成配音／音效制作清单。
4. 控制每段的动作数量。移动需给目标位置；镜头需给起终点；多人物视线、主客体和道具所属明确，写 clip 尾部衔接状态。
5. 约束只保留会改变结果的事项，如服饰不变、道具仍在右手、画面无字幕。若后端无独立 negative_prompt 字段，把约束并入正文，不能猜 API 参数。
6. 做时间、空间、参考映射和音轨自查，保存提示词与请求说明；交给 `jimeng-skill` 或 `generate-video-by-seedance`，只提交用户已选择的后端。

## 验收与恢复
没有“1 秒内停留 3 秒”之类矛盾；每个参考能指向真实已审核文件；同一 prompt 与参数可追踪。产物失败时判断是提示词、资产还是后端限制，先改一个具体问题再做小范围验证。
