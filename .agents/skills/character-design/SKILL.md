# 角色设计

## 目标与边界
造型服务于人物的经历、职业、行动习惯和叙事辨识。接受一句角色设定、人物小传或已审核资产表；用户只给新角色描述时也可独立创作。

## 输入与输出
输入人物身份、年龄段、性格、剧情职责、画风和明确的外貌设定。输出角色卡、锁定特征、16:9 横版三视图合图提示词及可选独立视图提示词。角色设定图比例与最终视频比例分别记录。

## 执行
1. 提取已有描述；用 `原文明确／创作补充` 区分。决定脸型、发型、体态、服装层次和配色、惯用手、代表道具及常见表情，解释关键造型如何服务剧情。
2. 每人一个固定 ID；建立 5–8 个足以辨认的锁定特征。不要以鼻型、胖瘦或族裔推断人格善恶；可通过服装、姿态和道具表达角色职责。
3. 合图默认：16:9 横构图、纯净中性背景；左侧面部近景，右侧正面／侧面／背面全身站姿，三视图为同一人物、同一套服饰、同一身体比例；不截脚，不让手和道具遮挡关键结构。
4. 明确无画面标注文字、无额外人物、无装饰边框；不要承诺能取消服务固有标记。需要情绪表／服装版本时单独生成，避免一张图塞入太多布局要求。
5. 写入角色资料与 prompt 文本。按用户选定后端交给 `jimeng-skill`、`generate-image-by-seedream` 或 `nano-banana-pro`；后端尚未配置时完成提示词即可，说明仍未出图。
6. 生图后比较正侧背脸型、发色、服饰构造、道具手位、轮廓与身材。保留通过的参考图和模型／参数／版本，后续引用同一文件。

## 验收与恢复
人物能凭轮廓与关键配色区分；视图之间为同一角色；创作补充可追溯。错误只重做相关视图；修改锁定特征需新版本并检查受影响镜头。只写提示词时标记 planned，生成后标记 generated，观看通过才 approved。

## 来源与限制
依据 [技能合集](https://bytedance.larkoffice.com/wiki/BdgQwEQPHi0EXckhyiOcT8cnn4c) 的角色设计用例重建；人物一致性仍依赖参考能力和实际审看。
