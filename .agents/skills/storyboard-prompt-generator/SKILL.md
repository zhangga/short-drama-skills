# 分镜图像提示词

## 目标与边界
输出静态关键帧，用于预演构图或参考视频。文字分镜确定时序，图像提示词描述某个时间点；不要让一张图同时完成连续动作。

## 输入与输出
输入已审核文字分镜、视觉资产及画面比例。输出按 shot_id 命名的 prompt 文本、资产引用映射和关键帧用途（构图参考／首帧／尾帧）。

## 执行
1. 选择每镜最能承载信息的瞬间。首帧写动作开始前状态，尾帧写完成后状态，别把同一描述复制成两帧。
2. 沿用角色 ID、造型与道具版本；明确人物左右位置、前后层次、景别、机位、视线方向和画面焦点。
3. 固定场景布局、入口出口与光源方向。换反打时核对轴线，不让人物和道具无因换位。
4. 每张图写完整静态画面和引用资产，移除“随后／旋转五秒”等运动叙述。首尾帧保持可达的动作状态。
5. 默认逐镜独立图；用户要多格故事板时才输出合图布局，同时保存独立 prompt，避免格内编号／对白文字污染视频参考图。
6. 用选定图像后端生成并检查人物一致性、场景构图、数量、道具手位。接视频时用后端支持的参考角色，不假定所有图都可当首帧。

## 验收与恢复
图与对应镜头的时间点一致，跨镜空间有依据。分镜图是可选中间产物：纯参考图视频流程已能表达镜头时，不强制每镜烧一张图。变更分镜后重做受影响图。

## 来源与限制
依据 [技能合集](https://bytedance.larkoffice.com/wiki/BdgQwEQPHi0EXckhyiOcT8cnn4c) 的故事板提示词能力重建；未提供原始模板，以上为功能实现。
