# 文字分镜

## 目标与边界
把叙事意图转成可拍的动作和镜头。先保留剧情因果，再分配时间；不按固定每秒一镜切碎表演。

## 输入与输出
输入剧本／片段、目标时长、画风比例、人物与场景资料、选定后端限制。输出人可读文字分镜及结构化 `storyboard.json`；字段与样例见 [格式](references/format.md)。

## 执行
1. 列出该段观众必须看懂的信息、情绪转折和前后剧情状态。把内心独白改为表演、道具、环境或必要旁白，保留有用的情绪目标作为导演注释。
2. 每镜写景别、视点、动作链、对白、声音、灯光和起止时间。将“紧张”具体化为动作，但不要靠堆叠小动作替代剧情。
3. 运镜交代起终点和运动对象；人物动作交代谁、用哪只手、碰什么、向哪移动、结束在哪。光源方向／软硬／昼夜优先，色温数字按需使用。
4. 按对白朗读、动作难度和情绪停顿分配时长。打斗或多人物互动优先拆为少量明确动作，避免在 1 秒同时要求拔剑、跳跃、环绕和慢放。
5. 每 clip 从 0 开始，连续覆盖目标时长；写 clip 间人物位置、视线轴、服装／伤势／道具及光线衔接。确认镜头尾部状态能成为下一 clip 的起点。
6. 调用 `scripts/validate_storyboard.py <分镜JSON> [--assets <资产JSON>]` 校验时序、ID 和资产引用。修正硬错误后再交给关键帧／视频提示词技能。

## 验收与恢复
故事信息可从画面／声音读懂；对白能说完；无自相矛盾的镜头停留时间。脚本只校验结构，不能证明故事、空间与表演合理。密度及对白速度提示仅是启发式，结合朗读和样片判断。

## 来源与限制
依据 [技能合集](https://bytedance.larkoffice.com/wiki/BdgQwEQPHi0EXckhyiOcT8cnn4c) 的动作、摄影、灯光原则重建；原文 15 秒示例含时序矛盾，本技能补入校验。
